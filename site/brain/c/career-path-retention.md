# Career Path Retention

Topic: Money & Unit Economics | Type: principle | Seen in 3 videos

## The idea (paraphrase)

Leila gives a nail salon chain that kept staff by offering a career path and paying for new skills, which lowers the pull of leaving to start a rival.
