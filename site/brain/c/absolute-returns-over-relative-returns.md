# Absolute Returns Over Relative Returns

Topic: Leads & Marketing | Type: principle | Seen in 3 videos

## The idea (paraphrase)

Alex says businesses get stuck optimising relative returns such as conversion rates, when absolute output from more inputs is what grows the business, even if the relative return falls.
