# Scalability Trade-off

Topic: Scaling & Strategy | Type: principle | Seen in 2 videos

## The idea (paraphrase)

Hormozi says needing humans does not make something unscalable; it is a cost and return question, so hiring is worth it if it earns more than it costs.
