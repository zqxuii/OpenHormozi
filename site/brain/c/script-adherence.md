# Script Adherence

Topic: Sales | Type: principle | Seen in 2 videos

## The idea (paraphrase)

Hormozi says sales teams should drill and reward strict script adherence, because off-script closes teach reinforced bad habits and only a team-wide script can be improved by testing.
