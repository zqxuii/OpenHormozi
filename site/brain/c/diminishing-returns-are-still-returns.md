# Diminishing Returns Are Still Returns

Topic: Scaling & Strategy | Type: principle | Seen in 2 videos

## The idea (paraphrase)

Alex's view that falling return per action is not a reason to stop, because you are still getting more in absolute terms when you do far more volume.
